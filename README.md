Breakout Rider: a deterministic pump.fun replay paper bot. It buys only curves already proving themselves — net SOL flowing in, several distinct buyers, price up a healthy amount but not yet parabolic, sitting near its window high — then pyramids into strength and exits on take-profit, trailing stop, hard stop, tape fade, or a big single dump. Paper money only, 10 SOL, no real trading.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (hello → batch → done), runs on Node 22 with zero dependencies, and is fully deterministic: no clock, no environment, no randomness.
